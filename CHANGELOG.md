# Changelog

## Unreleased

### Added
- MAC-address enrichment scalars (category `enrichment`): `oui_vendor(mac)`,
  `oui_lookup(mac) → STRUCT(prefix, block, organization)`, `mac_normalize(mac)`,
  `mac_is_multicast(mac)`, `mac_is_local(mac)`, `mac_is_broadcast(mac)`,
  `eui48_to_eui64(mac)`, and `mac_from_ipv6(address)`. `mac` accepts `VARCHAR` in
  colon / dash / Cisco dotted / bare-hex notation, a 6-byte `BLOB` (so they apply
  directly to IPFIX `raw_fields['sourceMacAddress']`), or an integer; invalid
  input yields `NULL`.
- Bundled IEEE Registration Authority MA-L / MA-M / MA-S registry snapshot
  (retrieved 2026-11-16 from standards-oui.ieee.org; ~54k assignments, ~1.1 MB)
  in `crates/netflow-core/data/oui/`, regenerated by `ci/gen-oui.py`.
- `ipfix_mac` golden fixture (`test/data/ipfix_mac.dat`) carrying
  sourceMacAddress / destinationMacAddress, a composed `flows` + `oui_vendor` +
  `mac_is_local` example, seven agent-suitability tasks, and `test/sql/mac.test`.

## 0.4.2 — 2026-11-14

### Changed
- Docs link to upstream sources (vgi-lint VGI183): the catalog `vgi.doc_md` now
  ends with a "Sources and references" section linking RFC 3954 (NetFlow v9), RFC 7011 (IPFIX), the IANA IPFIX registry and sFlow v5.

## 0.4.1 — 2026-11-14

### Fixed

- Schema-level example queries no longer read the placeholder capture glob
  `caps/*.dat`, which exists nowhere, so for every user they returned no rows
  (vgi-lint-check 2.7.0 VGI516/VGI913). The version-routing and
  INET-containment examples now read the committed sample captures
  (`test/data/{v5,v9,ipfix,sflow}.dat`) through release-tag-pinned
  raw.githubusercontent.com URLs and return real rows.
- README: the quick start decodes a sample IPFIX capture before listing the
  learned templates (a bare `templates()` on a fresh worker is empty), and the
  per-version and loss-check SQL examples read the pinned sample captures.
